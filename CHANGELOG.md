# Changelog

## 0.1.0 (2026-10-20), experimental
- First release: skill, references, scripts, starter config, style-reference frames.
- Page generator (`scaffold_page.py`) and hero generator (`make_stack_svg.py`), with honesty checks built in.
- Evaluated on two made-up briefs against a no-skill baseline, plus an independent finish review (see `evals/RESULTS.md`).
- Rules added from the review: headings must agree with tags, do not say more than the source says, quantity words need a source, dimmed text keeps contrast.
- 21 unit tests for the scripts, with CI.
