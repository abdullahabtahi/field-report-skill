# Style reference frames

Four graded frames from the first case study page (an exploded five-layer stack on near-black, hairline linework, one steel-blue signal path): the orbit at start, middle and end, and the start of the push-in.

Use them as the **style reference** when generating the next project's hero still: convert to PNG if the tool needs it (`dwebp orbit-start.webp -o orbit-start.png`), upload with `creations_upload_image`, and pass as `references: [{type: "style", identifier: <id>}]` (two is enough; orbit-start and orbit-end). Style only: change the layers, keep the grammar.

Why they are here: consistency across the owner's case studies is the point, and a reference image carries the line weight, grey and framing better than any prompt. They are the owner's own generated art, made on 2026-10-18 with Magnific (Seedance 2.5 clip from a generated still; the original still was itself generated with two uploaded style screenshots used for style only). They are graded frames, 800 px wide.
